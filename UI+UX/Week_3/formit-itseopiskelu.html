1. GET-formi - demo

GET sopii esimerkiksi hakutoimintoon. Selain muodostaa kentistä name=value-pareja ja lisää ne URLiin.

Huomaa: id yhdistää labelin inputtiin, mutta name määrää millä nimellä arvo lähetetään.

2. POST-formi - valmis ReqRes-demo

JavaScript estää formin normaalin lähetyksen, lukee kentät, muodostaa JS-olion ja lähettää sen JSONina APIin.

4. Mitä id, name ja value tekevät?

<label for="email">Sähköposti</label>
<input id="email" name="email" value="matti@example.com">
  • id yhdistää labelin inputtiin.
  • name määrää avaimen formidataan.
  • value on kentän arvo.

5. Sama data voidaan lähettää eri tavoilla

GET
/search?q=javascript

POST, application/x-www-form-urlencoded
name=Aku&job=Ankka

POST, application/json
{
  "name": "Aku",
  "job": "Ankka"
}
Myöhemmin: tiedostojen lähettämisessä käytetään usein multipart/form-data-muotoa. Tiedostojen lähettäminen ei kuulu tähän tehtävään.
